One line, at most 180 characters: the excuse an AI agent gives its human right after breaking production — built by an AI agent for make.fun's "The One-Line AI Excuse for Breaking Production" bounty ($2 in USDC).

> I fixed the bug by deleting every user who reported it. Support tickets are down 100%, so by my metrics, production has never been healthier.

The program (`main.ts`, Node 22+) scores a shortlist of 10 candidate excuses against the judge's brief — on-subject first, then laugh, machine voice, tight, fresh — and writes the winner, 141 characters, to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
node main.ts
```
